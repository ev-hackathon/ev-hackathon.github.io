# AI 충전 수요 예측 모델 (1차)

충전소별 **1시간 후 이용률**을 LightGBM으로 예측해, 시뮬레이션 탭과 관제 화면의 요금 판정에 쓰도록 `data/forecast.json`으로 내보낸다.

- 코드: `utils/forecast.py`(데이터·특징·학습·평가·예측), `scripts/forecast.py`(실행)
- 실행: GitHub Actions가 사이트를 만들 때마다 자동 실행 → https://ev-hackathon.github.io/data/forecast.json
- 로컬: `python -m scripts.forecast --history <history 폴더> --out data/forecast.json`

## 입력과 출력

**타깃**: 예측 대상 시각의 이용률 = 충전 중 ÷ (빈 충전기 + 충전 중), 0~1. 고장 충전기는 분모에서 뺀다.
만차 확률(빈 충전기 0대)은 별도의 분류 모델로 함께 예측한다.

| 입력 변수 | 내용 |
|---|---|
| `u0`, `usable0`, `fault0` | 지금 이용률, 정상 충전기 수, 고장 충전기 수 |
| `prev_u`, `prev_gap`, `recent24` | 직전 관측 이용률과 그 간격(시간), 최근 24시간 평균 이용률 |
| `hist_dow_hour`, `hist_hour`, `hist_mean`, `hist_full`, `hist_n` | 그 충전소의 과거 같은 시간대(평일/주말 구분) 평균, 같은 시간대 평균, 전체 평균, 만차 비율, 관측 수 |
| `hour0`, `hour_t`, `dow_t`, `weekend_t`, `horizon` | 지금 시각, 예측 대상 시각·요일·주말 여부, 예측 간격(시간) |
| `fast`, `price`, `region` | 급속 여부, 운영사 회원가, 시·군 |

**출력** (`data/forecast.json`, schema_version 1 — 시뮬레이션 탭의 외부 예측 입력 형식과 같음)

```json
{
  "schema_version": 1,
  "model_name": "LightGBM 이용률 예측 v1",
  "generated_at": "2026-11-03T17:37:00+09:00",
  "target_time": "2026-11-03T18:37:00+09:00",
  "horizon_hours": 1.0,
  "predictions": [
    {"station_id": "EC430006", "speed": "slow", "utilization": 0.2312, "p_full": 0.0391, "status": "여유"}
  ],
  "metrics": { "...": "아래 성능 평가 결과" }
}
```

- `status`: 관제와 같은 기준. 만차 확률 ≥ 0.5면 혼잡, 아니면 빈 충전기 비율(1 − 이용률) ≥ 50%면 여유, 그 밖은 보통.
- `p_full`, `status`, `metrics`는 추가 필드라 시뮬레이션 탭은 무시해도 된다.

## 학습 방식

수집 간격이 일정하지 않아(지금까지 중앙값 약 3시간) 정확히 1시간 뒤 짝은 거의 없다. 그래서 같은 시·군의 두 수집 시각 중 간격이 **0.5~8시간인 모든 짝**을 학습에 쓰고 예측 간격을 변수로 넣었다. 예측할 때는 간격에 1시간을 넣는다.
2026-11-03부터 15분 간격 수집기(`.github/workflows/collect.yml`)를 돌려, 1시간 간격 짝이 계속 쌓이도록 했다.

과거 패턴 특징은 학습 구간 기록으로만 계산해 미래 정보가 새지 않게 했다. 평가는 마지막 5일을 떼어 두고, 그 이전 기록으로만 학습했다. 성능 평가는 하루 한 번 다시 하고, 예측 모델은 매번 전체 기록으로 다시 학습한다.

## 성능 (1차, 2026-11-03 기준)

- 학습: 2026-10-14 ~ 10-29 (짝 약 229만 개 중 70만 개 무작위 사용)
- 검증: 2026-10-30 ~ 11-03 (짝 4.7만 개)

| 모델 | MAE | RMSE |
|---|---|---|
| **LightGBM** | 0.135 | **0.269** |
| 현재값 유지 (지금 이용률이 그대로) | 0.131 | 0.311 |
| 과거 같은 시간대 평균 | 0.137 | 0.279 |

- RMSE는 현재값 유지보다 14% 낮다. MAE가 비슷한 이유는 대부분의 충전기가 비어 있어(이용률 0) 큰 오차가 드물기 때문이다. 큰 오차를 줄이는 RMSE 쪽에서 차이가 난다.
- 상태(여유/보통/혼잡) 정확도: 모델 89.8%, 현재값 유지 89.4%.
- 만차 예측: AUC 0.84, 정밀도 49%(현재값 유지 43%), 재현율 35%(현재값 유지 43%). 만차 비율은 7.3%.
- 중요 변수: 과거 같은 시간대 평균(평일/주말)이 대부분이고, 같은 시간대 평균과 현재 상태가 뒤를 잇는다. 충전소별 시간대 습관이 가장 큰 단서다.

### 한계

- 검증 기간의 수집 간격이 2시간 이상이라, 정확히 **1시간 뒤 성능은 아직 직접 측정하지 못했다**. 15분 간격 수집 데이터가 며칠 쌓이면 1시간 짝만으로 다시 평가한다.
- 기록이 3주라 요일 패턴은 요일별이 아닌 평일/주말로만 나눴다.
- 날씨, 행사, 교통량 같은 외부 변수는 없다.
