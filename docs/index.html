요금 계산 방식

동적 단가 = 출력 구간별 기본 단가 × 혼잡 배수 × 시간대 배수
  1. 충전기 상태로 대기, 충전 중, 고장을 셉니다.
  2. 대기율은 대기 ÷ (대기 + 충전 중)입니다. 고장 난 충전기는 계산에서 뺍니다.
  3. 급속과 완속을 따로 판정합니다. 대기율이 기준 이상이면 여유(할인), 대기가 한 대라도 있으면 보통, 전부 충전 중이면 혼잡(할증)입니다.
  4. 혼잡하거나 고장 난 거점마다 반경 안에서 가장 가까운, 같은 속도가 여유인 거점을 안내합니다.

기본 단가는 2026년 4월 행정예고된 공공 충전요금 5단계(30kW 미만 294.3원부터 200kW 이상 391.9원/kWh까지)를 썼습니다. 최종 고시가 나오면 바꿔야 합니다.

충전기 데이터: 한국환경공단 전기자동차 충전소 정보 API(공공데이터포털). 시·군 경계: 통계청 2018 시군구 경계. 충전소 이름, 위치, 상태는 모두 실제 API 값입니다. 화면의 요금은 정책 시뮬레이션 값이며 실제 청구 요금이 아닙니다.
